adds a phone bench at index.html?bench (and ?bench&act=3, ?bench&act=4, ?bench&act=4&scene=2): after one tap it plays the act's busiest moments in real frames, then the busiest again with bloom off, pixel ratio 1.0, lamps off, AO off and on Low, and shows this device's frame times, draw times, GPU time where the browser offers it and draw calls, with Copy results. A bench is not a run: it sends nothing and keeps nothing. tools/perf-phone.mjs now sets up the same moments from one shared table (src/bench-moments.js).
