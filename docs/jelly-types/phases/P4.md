- **Model:** deep

First read `docs/jelly-types/README.md` (the rules for every worker) and `docs/jelly-types/spec-core.md`.

## Do

All behind the switch.

1. **The type's attack is the only attack.** With the switch on, a run fires only its type's `attack`: bubbles for Normal, the Fire shot for Fire, the lash for Tentacle. No type but Tentacle lashes.
2. **Fire as a main attack.** The Fire shot fires at the jelly's full Fire rate, with the type's `hit` multiplier in place of `ELEMENT_BASE`'s `rate` and `dmg`. Set `hit` to land in the damage budget (`spec-core.md`).
3. **One set of attack stats.** For the Tentacle jelly, Attack damage is the sting's damage, Fire rate is lashes a second, and Attacks is how many tentacles strike at once, each at a different bug. Tentacle reach stays its own stat. With the switch on, the Tentacle damage, Tentacle speed and Tentacles stats aren't read.
4. **Cards and Treasures that do nothing for a type aren't offered to it.** For Tentacle: Range, Attack size, Pierce. Add an `attack=` filter on the card or treasure; don't branch on the jelly's id.
5. **Looks** for Fire and Tentacle, as the type files describe. No new lights.
6. **Balance bot option.** Add `--type=<id>` to `tests/balance.mjs` so a later phase can compare types. Don't run the bot.
7. Run the Attack Feel audit for Fire and Tentacle as main attacks; update `src/stories/attack-audit.js`.
