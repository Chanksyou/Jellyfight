# P1: The jelly type and the switch

- **Model:** deep
- **Size:** M
- **Depends on:** nothing
- **Branch:** `types/p1`

First read `docs/jelly-types/README.md` (the rules for every worker) and `docs/jelly-types/spec-core.md`.

## Also read

- `src/stats.js` (`BASE_STATS`), `src/content.js`, `src/kdl.js`
- `src/run.js` (run state, the resume-after-reload save), `src/run-log.js`
- `worker/index.js` (the plausibility check) and `tests/run-log.test.mjs`
- `src/stories/kit.js` (`fresh`)

## Do

1. Add `content/jellies.kdl`: one `jelly "id" name="…"` per type, with its differences from Normal as `stat` lines, an `attack` (`bubble`, an element id, or `tentacle`) and a `hit` multiplier (1 for now). Enter all eight types from the table in `spec-core.md`. Load and validate it in `src/content.js` the way the other `.kdl` files are.
2. The run holds `run.jelly` (default `normal`). Its stat lines apply on top of `BASE_STATS` when a run starts. Nothing reads `attack` yet.
3. Carry `run.jelly` through the resume-after-reload save, the run log and score submission. The Worker's check accepts a missing type as `normal`, so old clients keep working.
4. Add the switch `GAME.types` as `spec-core.md` describes: `?types`, a dev-tools toggle, and `fresh({ types: '<id>' })`. A run with it on is a dev run.
5. Add the Jelly type entry to `GLOSSARY.md`.

## Stories

- `types/normal-is-todays-jelly` (Normal's stats equal `BASE_STATS`)
- `types/jelly-stats-apply` (a Fire run starts with Health 19 and Attack damage 7.5)
- `types/jelly-survives-reload` (act 2, `act: 2`)
- `content/jellies-load` beside the other content guards

## Done when

- With the switch off, nothing a player can see or measure has changed.
- With it on, a run can be started as any type and only its stats differ.

## Not in this phase

- Any attack change, the pick screen, or renaming.
