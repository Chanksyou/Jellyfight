- **Size:** M

- **Branch:** `types/p3`

First read `docs/jelly-types/README.md` (the rules for every worker) and `docs/jelly-types/spec-core.md`.

## Also read

- `src/words.js` (`TREASURE_WORDS`, `TIMED_WORDS`, `WHILE_WHEN`, `baseMods`)

- `src/stories/treasures.js` for how a treasure word's story is written

## Do

Build these six words. Each has one job, a one-line `doc`, named props, and a story. Nothing in `content/` uses them yet.

| Word | One job |
| --- | --- |
| `status-damage` | Hits on a bug with `status` do `more` extra damage. Props: `by`, `elites`, `per-stack`, `thaw` |
| `on-kill-of` | When a bug with `status` dies (or dies to `by`), do the { block } at its spot |
| `nth-attack` | Every `every`th attack (or a random 1 in `every` with `random=#true`) does the { block } instead |
| `stack-buff` | On `event` (kill, hit, arc, big-splash), +`amount` to a stat for `time` s, up to `stacks` |
| `while when="moving"` | A new `when` for the existing `while` word: true while the jelly is moving at full speed |
| `status-taken` | Bugs with `status` deal `less` damage to the jelly. Elites and the boss are exempt |

Then move today's hardcoded Shatter (3x and a thaw when Fire hits a frozen bug) onto `status-damage`, with no change in play. Its existing story must still pass.

Systems read the run's combined effects (`run.mods`), never ids, and talk through the event bus.

## Stories

- `treasures/status-damage`, `treasures/on-kill-of`, `treasures/nth-attack`, `treasures/stack-buff`, `treasures/while-moving`, `treasures/status-taken`
