# P6: The end-of-act Attack upgrade pick, and Fire's pool

- **Model:** deep
- **Size:** L
- **Depends on:** P4. Can run beside P5.
- **Branch:** `types/p6`

First read `docs/jelly-types/README.md` (the rules for every worker) and `docs/jelly-types/spec-core.md`.

## Also read

- `docs/jelly-types/types/fire.md` (the upgrade table)
- `src/run.js` (the boss reward, the evolution pick, `showBook`), `src/ui.js` (the Treasure pick)
- `content/treasures.kdl` (the element-upgrade block and `needs=`), `src/stats.js` (`rollTreasures`)

## Do

All behind the switch.

1. **Content home.** Add `content/upgrades.kdl`: `upgrade "id" jelly="fire" name="…" icon="…" text="…" { words }`. Upgrades use treasure words and feed `run.mods` like treasures, but are never in a chest, and each is one of a kind.
2. **The pick.** After each act's boss (acts 1, 2, 3): the Legendary pick as today, then a second pick of 3 Attack upgrades drawn from the type's pool, without ones already taken. Reuse the Treasure pick's screen with its own heading. For now the Legendary pick stops promising a new Element; the evolution pick is untouched until P9.
3. **Chests.** With the switch on, the every-3rd-chest slot is an ordinary Treasure, the six Element Treasures, the 30 Element upgrades and Power Bank are never offered, and neither are the six tentacle Treasures (Stinging Nettle, Tape Measure, Spaghetti Strand, Toaster Cord, Chopsticks, Paperclip Chain).
4. **Saves.** Upgrades taken ride the resume-after-reload save and the run log.
5. **Fire's 12 upgrades**, as its table says. Each new word gets a story.
6. Add Attack upgrade to `GLOSSARY.md`.
